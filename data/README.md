## Overview

The PMB Oncology Explorer transforms published oncology treatment data into an interactive decision-support dashboard. Users can explore treatment costs, survival outcomes, PMB eligibility, and evaluate how policy threshold changes affect funding decisions.

Rather than reading large tables in a research paper, users can interactively filter, visualise, and analyse the data through a modern web interface.

## Dashboard Sections

### Dashboard

Provides a high-level overview including:

- Total treatments
- Average treatment cost
- PMB eligibility distribution
- Cost summaries
- Interactive charts

### Dataset Explorer

Allows users to:

- Search treatments
- Filter by PMB status
- View treatment characteristics
- Explore underlying data

### Policy Scenario Analysis

Simulates changes to the survival benefit threshold used for PMB eligibility.

Users can:

- Adjust the survival threshold
- Instantly identify treatments that would lose eligibility
- Compare policy outcomes under different scenarios

## Why This Project?

Healthcare policy decisions often rely on complex research tables that are difficult to interpret.

This dashboard demonstrates how interactive analytics can make healthcare evidence easier to explore, supporting more transparent decision-making and communication.
